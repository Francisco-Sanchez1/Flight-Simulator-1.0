# Flight-Simulator-1.0
Building a simple flight simulator. Simple controls which takes into account basic flight maneuvers.

Currently building cockpit ALT, SPD, HED in a HUD utilizing SFML.
Controls
- Speed
-   W : increase speed
-   S : decrease speed
- Altitude
-   q : increase altitude
-   e : decrease altitude
- Heading
-   A : turn left heading
-   D : turn right heading
